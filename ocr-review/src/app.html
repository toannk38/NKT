    Kéo-thả thư mục gốc vào đây hoặc

    Cấu trúc thư mục: mỗi thư mục con là một hồ sơ, gồm 1 file tài liệu (.pdf, .png, .jpg, .webp, .bmp, .gif) và 1 file .json kết quả OCR.

    thu_muc_goc/
├── ho_so_1/  giay_to.pdf   giay_to.json
├── ho_so_2/  anh.png       anh.json
└── …

    Kết quả duyệt được ghi thành <tên-json>.reviewed.json ngay trong thư mục hồ sơ. File JSON gốc không bao giờ bị ghi đè.
